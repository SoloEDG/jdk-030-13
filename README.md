# 栈闩工房

机关推箱子纯前端工房。不同种类的箱子触发对应踏板，踏板改变门与地板，记录步数并保存已完成关卡的最佳成绩。

## 齿条借调（借货装门）

`lend-*` 关卡引入第二套开门机关，与踏板机关并存：

- 货箱上挂着有限齿条，每根有颜色和跨距（reach），只能沿同一横/纵直线借给同色门。
- 一根齿条一次只能撑一扇门的一个门眼；长门有两个门眼，必须由**相反方向**的两根齿条同时对撑。
- 规划盘里逐扇门查看“能否单开”和具体调借实例；勾选一组门后判断能否**同开**。
  “各自借得到”不等于“这组借得到”——同色门可能争抢同一根齿条。
- 冲突时给出一个极小冲突门集：再少任一扇即可成立，并提示可移除的门。
- 把可行的一组“钉住”后，调借随每一步移动**原子重算**：搬箱导致借不齐时，
  齿条收回与门关闭、通行判定在同一步生效，借不齐的色门无法先穿过再补报。

## 本地运行

```bash
npm install
npm run dev
```

类型检查与生产构建：

```bash
npm run typecheck
npm run build
```

逻辑测试（Node 原生 TS，含匹配/冲突/原子校验与三关 BFS 可通关验证）：

```bash
npm test
```

## Docker

```bash
docker compose up --build
```
